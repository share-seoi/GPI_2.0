GPI 2.0 처음 실행 안내

아래 순서대로만 하면 됩니다.

1. Node.js를 먼저 설치하세요.
   LTS 버전을 받으면 됩니다.
   https://nodejs.org/

2. GPI_2.0 폴더를 여세요.

3. 처음 한 번만 이 파일을 더블클릭하세요.
   1_INSTALL_FIRST.bat

4. 설치가 끝난 뒤, GPI를 쓸 때마다 이 파일을 더블클릭하세요.
   2_RUN_GPI.bat

5. 브라우저가 자동으로 열립니다.
   안 열리면 아래 주소를 직접 여세요.
   http://127.0.0.1:8787

6. 앱 위쪽 가운데에서 로그인/키 입력을 합니다.
   OpenAI 사용:
   "chat gpt oauth 로그인" 버튼 클릭

   Gemini 사용:
   "gemini api key 입력" 버튼 클릭

주의:
GPI를 쓰는 동안 검은 서버 창은 닫지 마세요.
GPI를 끄고 싶으면 그 검은 창을 닫으면 됩니다.
